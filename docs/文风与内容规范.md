# 文风与内容规范

所有剧情模块（M5–M8）写正文前必须通读本文件，交付前逐条自查。

## 文风硬性规则

1. 每句话有明确主语，不写无主语句；主角用「你」，NPC 用名字或代词，指代不得产生歧义。
2. 文笔平实普通，语句简化，先保证逻辑通顺再考虑修饰；不堆形容词，不写华丽排比。
3. 禁止主观表述：不出现「我觉得」「我认为」「似乎觉得」「不禁」这类句式；心理活动直接陈述（「你不信他」而非「你觉得他不可信」）。
4. 减少句号，多用逗号、分号衔接；一个自然段通常一到三个句号；不为断而断，衔接必须符合语言逻辑。
5. 删除口水话：不写「嗯…」「那个…」「怎么说呢」之类的注水口语；对白短促有信息量，符合角色身份（老秦话少句短，灰猫句子带钩子，林晚用词冷静克制）。
6. 描写从感官落笔（视觉、气味、声音、触感），不解释情绪结论，用细节让玩家自行感受。
7. 每个 passage 正文一般 60–150 字，大型事件可到 300 字，超过就拆段落，手机屏一屏内读完为宜。

正误示例：

- 误：走进医院，觉得气氛很压抑，似乎有什么不好的事情发生过。
- 正：你走进医院，消毒水味压不住底下的腐味，走廊灯管闪了两下，护士站的椅子倒在地上。

## 前后自洽规则

1. 剧情节拍只能写 [NPC设定.md](NPC设定.md) 大纲中登记过的内容，新增节拍先补登记。
2. 每段剧情开头的 cond 必须锁前置 storyFlag，结尾 fx 必须写入本段 flag，禁止裸放剧情。
3. 引用其他 NPC 或暗线时，只使用关系网和暗线一节登记的信息，不揭晓未定真相（方舟真伪、病毒来源、灰猫买家）。
4. NPC 已知信息不回退：主角已告知的事、已发生的大事件，后续文本不得当作未发生；用 flag 做文案分支。
5. 时间敏感文案用 text 函数按 state 分支（如白天/夜晚、醉酒中），不写与当前时段矛盾的描述。

## 成人内容尺度

1. 所有性内容参与者均为成年人，全部角色年龄已在设定中登记为 23 岁以上。
2. 性描写直白、具体，允许露骨用词，但服务于关系推进，不做无剧情的纯堆砌；单段性事件 300–600 字，拆多个 passage 呈现，玩家选项参与过程。
3. 性内容以双方自愿为原则，发生在对应好感阶段（亲密以上，个别登记过的在信任阶段）。
4. 血腥暴力允许直接描写伤口、肢解、死亡过程，用于渲染末日残酷；不描写对无抵抗者的虐待细节取乐。
5. 成人段落同样遵守文风规则和标签规则，`[lust]` `[blood]` 标签照常只上名词。
6. 按主角性别分支的段落，用 `text: (s)=> s.player.gender==="f" ? ... : ...` 实现，分支只覆盖必要描写差异，共用部分不复制两份。

## 文字标签使用规范

1. 标签清单与颜色见 [Schema.md](Schema.md)，禁止发明新标签。
2. 只给名词上标签；一个 passage 内同一名词只标注第一次出现。
3. 每个 passage 彩色标签总数不超过 5 个，动效标签（horror/flash）最多 1 个，仅用于真正的高潮点或致命警示；平静日常段落可以完全没有标签。

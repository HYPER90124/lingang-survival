# M22 任务书 — 怀孕系统（模型：fable）【依赖 M14 迁移先例 + M17 家园，全批最后】

## 开工前必读
PLAN.md（M6 成人事件模式、M14 存档迁移、M17 homeStorage 接口 + v1.2 拍板备注）、docs/NPC设定.md、docs/文风与内容规范.md、js/engine/save.js、js/engine/time.js 日历机制。

## 目标
DoL 式长周期怀孕系统的临港版：羁绊阶段、玩家知情选择下可发生，覆盖女性主角怀孕与女性 NPC（qin/lin/mao/su）怀孕两个方向（候选池第二批 P）。

## 设计
- **发生前提（硬门槛，写死在 cond）**：对应 NPC stage=4（羁绊）+ 该 NPC 的 s4_2 亲密变体事件中新增「不避孕」选项（默认选项仍是避孕；选择即知情）。选后按概率（0.25/次，常量）写 `npc.{id}.pregnant` 或 `player.pregnant:{by:id}`。
- **孕期**（游戏内 60 天，三阶段各 20 天，日历自动登记产检类 appointment 3 次，appointment+eventId 强制触发，照 M8 尸潮链写法）：
  - 主角怀孕：分阶段 debuff（负重 -10/-20、精力消耗 +10%/+20%、孕晚期不可进 metro/sewer 等高危点——cond 层拦截 + 文案），NPC 父亲侧每阶段 1 段剧情；身体面板显示孕期状态。
  - NPC 怀孕：该 NPC 作息变化（孕晚期居家/移到 home 或其据点）、scheduled 事件停摆、每阶段 1–2 段探望剧情；其战斗同行（M18）资格冻结。
- **生产**：期满日历强制事件（@hospital 或据点，lin 在场与否出变体；文案尺度按规范，重血腥不渲染）；产后写 `npc.{id}.child` / `player.child`，孕期 debuff 解除。
- **婴儿承载**：不做养育玩法（红线——工作量黑洞），做「存在感」：home 需已修 M17 储物柜级别的安置（未修则触发一次置办事件消耗材料）；每日跨日消耗 +1 食物当量（从 homeStorage 自动扣，断供掉 NPC 好感与理智，不死婴——文案写邻里接济兜底）；各相关 NPC 3–5 条日常变体台词；孩子作为长线氛围存在。
- **避孕道具**：items.js 上架（zhao/su 渠道），s4_2 的默认避孕选项消耗之；无货时「不避孕」不再是概率而是明示风险——道具缺货即变相提高发生率，与 M20 缺货机制自然联动。
- **存档**：pregnant/child 结构走 SAVE_VERSION 迁移；孕期用绝对天数存起点，读档重算阶段。

## 约束
- 知情选择红线：任何怀孕都必须来自玩家在明示选项上的主动选择，无「暗算」式设计；成人内容尺度照既有规范。
- 多 NPC 同时怀孕允许但产检/剧情事件要错峰（priority 与同日去重照 M6 周期事件模式）。
- debuff 数值以 M9/M15 基线复测：孕期主角 30 天生存机器人 ≥4/5（孕期是难，不是判死刑）。

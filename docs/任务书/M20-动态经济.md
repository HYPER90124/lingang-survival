# M20 任务书 — 动态经济（模型：sonnet）

## 开工前必读
PLAN.md（M3 trade 形状、M8 世界链、M9 平衡备注、M19 交接备注 + v1.2 拍板备注）、js/data/trade.js 全文、js/engine/time.js dayRollover。

## 目标
物价随世界状态波动、商店会缺货，商人间有差价套利空间；子弹经济中后期不失衡（候选池第二批 Q）。

## 设计
- **价格乘数层**：trade.js 加 `priceMod(itemId, shopId)`，shopBuy/shopSell 统一过这层；UI 货架显示当前实价，波动时标注涨跌箭头（↑↓，panels.js 商店浮层小改）。
- **波动源**（全部读现有 world 旗，跨日结算算好存 `world.market:{mods,shortage}`，当日恒定防刷）：
  - 尸潮夜次日：食/水/绷带 ×1.5（持续 2 天）。
  - 雨天：水类 ×0.7。
  - `world.butcherFallen`（M19）后：子弹进货松动，fang_ammo 子弹类 ×0.8，持续性生效；未收网时收账队事件当日 zhao_main 全线 ×1.2（保护费转嫁）。
  - 随机缺货：每个 restock 日 15% 概率某 tier 随机 1–2 种货缺货至下次进货（货架显示「缺货」）。
- **差价套利**：给 3 商店各定 1–2 种「本行便宜、外行贵」的品类差（如 fang 军货便宜杂货贵、zhao 反之），差价幅度 20–30%——搬货套利有利润但受负重与路程时间约束，算不过中期搜刮期望（红线，用 M9 探针法验证）。
- **波动边界**：总乘数钳制 [0.6, 1.8]；剧情礼物/非卖品不受影响；cai_barter 以物易物不动（它的价值锚定就是乱世感）。

## 约束
- 只改 trade.js + panels.js 商店浮层 + dayRollover 挂结算；COMBAT/生存 TUNE 不碰。
- `world.market` 走 migrate 补默认；老档读入首日按无波动处理。
- 机器人验证：30 天胜任基线不许被物价波动打破（5/5 保持）；套利路线跑一遍确认时薪低于搜刮。

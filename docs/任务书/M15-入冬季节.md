# M15 任务书 — 入冬季节压力（模型：opus）【依赖 M14 的 warmth 属性，必须排在 M14 后】

## 开工前必读
PLAN.md（M9 平衡备注 + M11 水源备注 + M14 交接备注）、js/engine/time.js（TUNE 与日结算）、docs/世界观.md 日历规则。

## 目标
开局第 90 天=10 月 12 日，让时间流逝有季节后果：入冬带来温度压力，消费 M14 的保暖属性、联动 M11 的水源系统。

## 设计
- **季节曲线**：按游戏日算温度档（秋 → 初冬 day~140 → 深冬 day~170），挂 `world.season`；文本层地点描述按季节加一句变体（descDay/descNight 改 text 函数或加季节后缀，从简）。
- **寒冷机制**：新增 body 状态 `cold`（0–100）。室外活动按温度档与 warmth 差值累积，室内/生火消退；阈值效果照感染/毒瘾的既有模式（>50 精力上限降、>80 掉血）。集中常量进 `TUNE`。
- **联动**：
  - M11 水源：深冬江边取水需破冰（耗时翻倍），接雨水改接雪（产出减半）；煮水行动兼做「取暖」（cold 消退）。
  - 尸潮/敌人：冬季丧尸迟缓（speed -1 下限 1）但玩家消耗大——冬天是「敌弱我更弱」，不是纯难度堆叠。
  - 商店：保暖衣物冬季涨价、上新（数据层 restock 变体）。
- **事件**：寒潮预警（仿 M8 尸潮链的 appointment 写法）、雪天氛围池 6–8 条、冻毙的流浪者（拾取衣物的道德小分支）各地点 2–3 条。
- **存档**：cold 字段走 migrate 补 0；老档进冬季正常生效。

## 约束
- 平衡基准：胜任机器人 60 天生存（跨入初冬）成功率 ≥4/5；冬季必须靠 M14 服装或囤柴火（可加 firewood 道具）才能长时间外勤，但住家躺平也不能安全（饥渴照旧逼你出门）。
- 温度只做档位不做连续模拟，别过度工程。
- 所有新常量进 time.js TUNE 集中管理。

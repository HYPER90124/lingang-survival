# M18 任务书 — NPC 同行作战（模型：opus）

## 开工前必读
PLAN.md（M4/M10/M13 交接备注 + v1.2 拍板备注）、js/engine/combat.js 全文（M10 改造后版本）、js/data/npcs.js 作息表与 talkTo 机制。

## 目标
好感≥60（亲密+）的战斗型 NPC 可邀请短期同行，战斗中作为我方第二单位（候选池第二批 M）。

## 设计
- **可同行者**：qin（近战强，dmg 8–14）、dou（枪，dmg 6–12 无限弹但命中 0.7）、mao（不参战，同行时逃跑成功率 +0.15 与遇敌 chance -30%——侦察定位）。三人数据存 npcs.js 新增 `companion:{}` 字段。
- **邀请**：talkTo 菜单在 aff≥60 且 NPC 在场时出「同行」选项；同行到当日 24:00 或玩家回 home 主动解散；同一时间最多 1 人；NPC 作息时段外不可邀（lin 值班不做同行，医疗价值在既有事件里）。状态存 `world.companion:{id,until}`（易失场景少，入档，migrate 补 null）。
- **战斗**：combat.js 增我方单位数组——同伴在玩家行动后自动攻击（AI 就打 firstAlive）；敌方每回合按 50/50 分配目标打玩家或同伴；同伴 hp 独立（战斗内临时值，进场满血），**降到 30% 自动撤出战斗**（不死——剧情 NPC 不能死在随机战里），撤出后本场不再回来，当日同行结束，好感 -2。
- **同行氛围**：移动/搜刮时低频触发同伴对话池（每人 4–6 条，enter/action、chance 0.15、cooldown 240）；同行时搜刮负重上限 +10（帮拿）。
- **平衡**：同行是强增益，要有成本——每次邀请消耗好感 3（人情）或一份食物/酒（招待，玩家选）；同行期间该 NPC 的 scheduled 事件（巡逻夜/义诊日等）不触发。
- **与 M19 联动预留**：companion 机制做成通用（按 id 配置），M19 战役强制同行段落直接复用。

## 约束
- combat.js 改动保持 M10 的 combatOptionInfo 正确（逃跑公式如受同伴影响要同步进显示）。
- 同伴数值别让 zombie_pair 级战斗变白给：机器人测试对比同行/单人的胜率差控制在明显但不碾压（参考：中级编组胜率 +20~30 个百分点）。
- 战败结算：有同伴时对人类敌人的战败非死亡流程（M13-A）照走，同伴文案跟一句；对丧尸战败仍死亡。

# M8 任务书 — 边缘 NPC 与世界事件池（模型：fable）

## 开工前必读
PLAN.md、docs/NPC设定.md（边缘三人）、docs/世界观.md（地点表 + 暗线）、docs/文风与内容规范.md、M3 交接备注（编组清单）、M5–M7 交接备注（flag 清单，用于世界事件引用剧情进度）。

## 目标
补全游戏的随机内容层，产出 `js/data/story/minor.js`（边缘 NPC）与 `js/data/story/worldevents.js`（世界事件池）。

## 范围
1. **边缘 NPC**：陈神父、老蔡、方哨各 2–3 段互动，机制落地——告解理智恢复（每日一次）、老蔡随机换物、方哨弹药交易；方哨登记过的可选成人段（fang_s2_3）。
2. **地点事件池**：15 个地点各 4–6 条 random 事件（M3 打底的 2–3 条之外补足），按危险度和时段分布：遭遇战、发现物资、幸存者掠影、氛围事件、罕见奇遇（每地点至少 1 条低概率高回报）。
3. **状态触发事件**：sanity<20 幻觉池（4 条起）、alcohol>60 醉酒事件（3 条）、addiction>50 毒瘾发作日事件（发作/硬扛/找药三分支）、infection>80 濒死线（限时,林晚在场分支）。
4. **全局周期事件**：尸潮夜（低概率整夜事件，全地图危险度上调，日历可提前一天从广播/情报获得预警）、雨天（当日采集加成 + 氛围文案变体）。
5. **屠夫帮世界线**：3–4 条与主线 flag 联动的随机遭遇（读 qin/mao 线 flag 出对应变体），只做变体不推剧情。

## 写法要求
- random 事件无前置依赖、可重复（设置合理 cooldown），文本短小（60–100 字为主）。
- 状态事件是玩家最常复读的内容，每类多写变体防重复感。
- 文风自查照旧；血腥描写主要集中在本模块的遭遇事件，按内容规范执行。

## 验收
每个地点蹲出至少 3 条不同事件；四类状态事件用控制台调数值逐一触发；尸潮夜预警→发生的完整链路走通。

# M6 任务书 — 主要 NPC 剧情·亲密与羁绊（模型：fable）

## 开工前必读
PLAN.md、docs/NPC设定.md、docs/文风与内容规范.md（成人内容尺度节重点读）、M5 交接备注的 flag 清单，通读 M5 产出的三个 story 文件确认衔接。

## 目标
续写 qin/lin/mao 三人亲密、羁绊两阶段全部剧情，追加到 M5 的三个文件内。

## 范围
1. 每人亲密阶段 3–4 段（含大纲登记的大型事件：老秦遇伏救援、林晚实验楼委托、灰猫隧道被困夜）、羁绊阶段 3 段以上，合计每人全线 15+ 段达标。
2. **成人内容**：每人亲密阶段首段性事件 + 羁绊阶段 1–2 段变体；按性别分支实现；尺度、字数、passage 拆分、选项参与全部按内容规范执行；性事件同步影响身体状态（精力消耗等）。
3. 羁绊阶段落地各自的周期事件（老秦巡逻之夜、林晚义诊日、灰猫每周情报），注册为 scheduled 事件并写入日历标记；灰猫真名揭露事件。
4. 三条线的收尾都保持开放循环，不写终局。

## 写法要求
- 与 M5 的 flag 严格衔接，升阶 fx 在转折剧情内执行。
- 大型事件允许战斗穿插（用 M3 编组）与失败分支（失败不掉线，留重试或替代路径，禁止死档）。
- 成人段落文风与叙事段落一致，不切换成另一种腔调。

## 验收
三条线从信任推到羁绊满：大型事件胜/败两分支都走通，性别两套开局各验一条线的成人段落，周期事件按星期正常触发并出现在日历。

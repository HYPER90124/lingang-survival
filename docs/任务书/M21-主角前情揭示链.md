# M21 任务书 — 主角前情揭示链（模型：fable）

## 开工前必读
docs/世界观.md 暗线节（主角前情的既定口径，**本模块唯一事实源，不许超纲发明**）、PLAN.md（M5 开场备注：worn_idcard 发放、M8 备注：halluc_5 正向闪回）、js/data/story/intro.js、worldevents.js 的 halluc 池。

## 目标
把 worn_idcard 和幻觉闪回两处埋点收成一条 5–6 节记忆碎片链，中期给一次身份揭示；纯叙事，不动玩法（候选池第二批 O）。

## 设计（新增内容并入 worldevents.js 尾部独立 IIFE 或新文件 story/memory.js，二选一记交接备注）
- **触发**：各碎片绑定地点 + 需 worn_idcard 在包 + day 门槛递进（碎片1 day≥5 … 碎片5 day≥18），enter/action、chance 0.25、cooldown 1440、once，彼此 flag 锁序（world.mem1~5）。
- **地点选择**：从与前情口径相关的地点里选 5 个（世界观暗线定什么就用什么；候选：hospital 档案、police 登记簿、checkpoint 撤离名单、metro 站台遗留、home 旧物）。每节 2–3 段，碎片信息只给「一角」，理智 -2~+3 按内容定。
- **揭示节点**：world.mem5 后下一次睡眠触发揭示梦境事件（once，长文本），醒来写 `world.memDone` + 理智上限观感文案（不改数值上限——纯叙事红线）。揭示内容必须与世界观暗线口径完全一致，若暗线未定死细节，在不越权范围内收口并**回写 docs/世界观.md 登记**（M6 定孟九名字的先例）。
- **联动**：halluc_5（正向闪回）在 memDone 后换一版呼应文案（读 flag 分支，不新增事件）；lin/qin 若 aff≥60，各给 1 条搭话变体（玩家可对其提起身世，点到即止）。
- **错过兜底**：worn_idcard 是开场发放的普通道具，可能被玩家丢弃——碎片链 cond 同时接受 `world.mem1:true`（链一旦开头就不再要求卡在包）；卡被丢弃且链未开头时，market 旧货摊加一条低概率回购事件把卡送回来。

## 约束
- 不改任何数值系统；新事件全带 chance/once；性别双分支文案照规范。
- 揭示不得与已交付剧情台词冲突（M12 的豁免清单里涉主角过去的条目先读一遍）。

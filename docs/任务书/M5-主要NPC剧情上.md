# M5 任务书 — 主要 NPC 剧情·前中期（模型：fable）

## 开工前必读
PLAN.md、docs/NPC设定.md、docs/文风与内容规范.md、docs/Schema.md（passage/事件/条件/效果节）、M4 交接备注中的注册范例。

## 目标
写老秦（qin）、林晚（lin）、灰猫（mao）三人警惕→熟识→信任三个阶段的全部剧情，产出 `js/data/story/qin.js`、`lin.js`、`mao.js`（各自前半部分），并登记开场剧情。

## 范围
1. 每人每阶段 3–4 段剧情事件（含初遇），合计每人 9–12 段，每段 2–6 个 passage。
2. 大纲中该阶段的机制解锁随剧情落地：老秦近战技巧（skill:melee）、林晚包扎（skill:bandage）、灰猫情报购买与下水道捷径（world.flags）。
3. 跑腿/委托类节拍用 M3 预留的剧情道具 id 与地点，委托目标写入日历 appointments。
4. **开场剧情**：安全屋醒来的开场 passage 组（替换 M2 占位），交代背景、引导去酒吧（自然引出老秦初遇）。
5. 阶段升阶事件：每人警惕→熟识、熟识→信任的转折剧情内执行 stage fx。

## 写法要求
- 逐条遵守文风与内容规范，交付前按其自查清单过一遍。
- 每段事件 cond 锁前置 flag，结尾写本段 flag，编号按 `npcId_s{阶段}_{序号}`。
- 信任阶段允许暧昧与压迫感铺垫，成人正文留给 M6；灰猫线登记过的信任阶段越轨事件除外。
- 涉及暗线（屠夫帮、病毒碎片、方舟）只用 NPC设定.md 登记的信息。

## 验收
实际游玩三条线从初遇推到信任满，无卡死、无跳序、无重复触发；开场流程完整。

## 完成后
勾选 PLAN.md M5，交接备注写：三人已用 flag 清单（M6 要接）、对大纲的微调（如有，同步改 NPC设定.md）。

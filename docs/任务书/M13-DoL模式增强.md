## 背景
用户要求参考《Degrees of Lewdity》的模式完善游戏。DoL 的核心循环 = 生计压力（钱/时间）× 日常事件密度 × 关系推进 × 战败非死亡。本作已有其中的地图/时间/好感/事件池骨架，缺的是下面这些。

## 候选功能清单（按性价比排序，用户逐项拍板 ✅/❌）

### A. 战败非死亡（人类敌人）—— 强烈推荐，直接缓解难度挫败
- [x] 现状：任何战败=死亡读档。改为：对**人类敌人**（屠夫帮）战败 → 被洗劫（丢一半物资+若干子弹）+ 重伤（hp 设 15、sanity -10）+ 在原地/教堂醒来；丧尸战败仍死亡（被吃了没得商量）。
- DoL 对应：defeat 机制（战败进惩罚流程而非 game over）。
- 实现：combat.js `onLose` 默认路由按敌人 human 字段分流（M10 已加 human 标记）；引擎小改 + 两三段「醒来」文本。

### B. 打工/生计系统 —— 推荐，补「搜刮之外的第二经济」
- [x] 酒吧帮工（su，好感≥20 解锁）：晚间 3 小时 → 子弹×3 + 偶发酒客事件。
- [x] 医院助手（lin，≥40）：白天 4 小时 → 子弹×4 + 绷带，偶发伤员事件（可挂 bandage 技能加成）。
- [x] 码头搬运（cai/dock）：无门槛重体力，4 小时 → 子弹×5，精力大耗，偶发走私/尸潮前兆事件。
- DoL 对应：jobs（咖啡馆/舞蹈室等）。全数据层：scheduled 事件 + choice fx，引擎零改动。

### C. 魅力路线：遭遇的非战斗解法 —— 推荐，DoL 最典型的「每个遭遇多条出路」

# M2 任务书 — 移动端 UI 与文字标签系统（模型：sonnet）

## 开工前必读
PLAN.md、docs/Schema.md（文字标签节、GameState 节）、M1 交接备注、js/engine/main.js 与各引擎文件头部的接口注释。

## 目标
实现全部界面层：手机竖屏优先的 UI、文字标签解析、各功能面板。产出 `css/style.css`、`js/ui/` 全部文件，替换 M1 的 G.ui 占位函数。

## 设计基调
- 深色主题：近黑背景 #141414，正文浅灰 #c8c8c8，衬线感中文字体栈，行高宽松，正文字号 17px 起。
- 竖屏单列布局，全部可点区域最小 44px，禁用缩放，safe-area 适配；桌面浏览器居中限宽 480px。

## 产出
1. **顶栏**：左侧天数 + 时刻 + 时段图标，点开日历面板；右侧子弹数、当前地点名。
2. **状态条区**：hp/饥饿/口渴/精力四条常显迷你条，点开身体面板看全部八项（数值 + 阈值状态描述，异常项变色）。
3. **主区域**：passage 正文渲染 + 选项按钮列表；地点界面（地点描述、行动列表、可见 NPC 列表、移动按钮）。
4. **底部导航**：地图（节点图，用 CSS/SVG 画相邻关系，点击移动）、背包（分类页签、道具详情弹层、使用/装备/丢弃）、身体、日历、系统（存档 3 槽 + 导出导入、关于）。
5. **日历面板**：当月月历网格，今日高亮，约定/周期事件/重要日子三类标记，点日期看当天条目，可翻月回顾。
6. **战斗界面**：敌人名 + hp 条、战斗文本滚动区、五个行动按钮、武器耐久显示。
7. **`js/ui/tags.js`**：按 Schema 标签表解析 `[类型:参数]文本[/类型]` 为 span；实现 horror（颤抖）/flash（闪烁）两个 CSS 动画；**强制执行每 passage 动效标签最多 1 个，超出降级为纯色**；NPC 专色从 G.data.npcs 读取。
8. **开局流程**：性别选择、姓名输入、开场 passage 的呈现（开场文本用占位，M5 替换）。

## 约束
- 不写任何游戏内容数据；演示用假数据放独立的 `js/ui/_demo.js`，标注 M9 打包时剔除。
- 只实现 M1 注释的 G.ui 接口 + 面板内部逻辑，不改引擎文件；接口不够用时新增 G.ui 方法并在文件头注释登记。

## 验收
手机浏览器（或 375px 视口）走通：开局创建 → 地点界面 → 打开每个面板 → 演示 passage 渲染（含全部 9 种标签）→ 演示战斗界面。无横向滚动，无 300ms 点击延迟。

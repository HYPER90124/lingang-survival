# 世界观设定

游戏名（暂定）：《临港余生》
类型：丧尸末日文字冒险，无结局，生存 + 人际经营循环。

## 背景

滨海中型城市临港市。当年 7 月 14 日（第 0 天，周一）病毒爆发，感染者死后化为行尸，军队封城失败，一个月后撤离，城市沦为无政府区。幸存者聚成松散据点，靠搜刮和以物易物过活，子弹是公认硬通货。

主角在第 90 天（10 月 12 日，周日）于一间陌生公寓中醒来，头部带伤，此前记忆模糊。这间公寓成为安全屋，游戏由此开始。

主角性别开局可选（男/女），姓名可输入，性别影响部分剧情分支与成人内容描写，剧情主体两性共用。

## 时间与日历

- 最小时间刻度 10 分钟，每个行动有耗时。
- 时段划分：清晨 05:00–08:00 / 白天 08:00–17:00 / 黄昏 17:00–20:00 / 夜晚 20:00–05:00。夜晚丧尸事件权重加倍，部分地点关闭。
- 日期换算：第 0 天 = 7月14日周一。第 N 天的星期 = N%7（0=周一）。月份天数按真实历法（7月31、8月31、9月30、10月31、11月30、12月31……），跨年继续推。
- 日历面板：显示当月月历，标记周期性事件（周响的周三晚广播、赵铁的周五进货日等）、剧情中产生的 NPC 约定、玩家经历的重要日子（初遇、重大事件）。
- 星期参与事件判定，周期事件由引擎按 weekday 调度。

## 核心循环

白天出门搜刮物资、推进 NPC 剧情、完成小任务线索；管理八项身体状态；夜晚回安全屋睡觉或冒险夜探；子弹用于交易；好感度解锁 NPC 阶段剧情与成人内容。没有通关条件，死亡后可读档。

## 派系与暗线（供剧情模块埋伏笔）

- 「屠夫帮」：占据商场的敌对幸存者团伙，多个随机遭遇与老秦线、灰猫线关联。
- 「方舟」电台传言：城外存在军方安全区，周响线与方哨线共享该传言，真伪不揭晓，维持无结局结构。
- 病毒来源：大学实验楼有零散文件暗示，与林晚线、灰猫线关联，只给碎片不给完整答案。

所有剧情模块引用本节暗线时，只能使用已在 [NPC设定.md](NPC设定.md) 各线大纲中登记的信息，不得私自揭晓真相或制造矛盾设定。
